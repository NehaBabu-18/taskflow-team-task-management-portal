========================================
TaskFlow - Terminal Commands Reference
========================================

WINDOWS USERS - Copy and paste these commands into Command Prompt or PowerShell

========================================
1. CREATE VIRTUAL ENVIRONMENT (Windows)
========================================
python -m venv venv
venv\Scripts\activate

========================================
2. INSTALL DEPENDENCIES
========================================
pip install -r requirements.txt

========================================
3. CREATE DATABASE (Windows)
========================================
mysql -u root -p
CREATE DATABASE taskflow_db;
USE taskflow_db;
source database.sql;
EXIT;

========================================
4. RUN APPLICATION
========================================
python app.py

========================================
5. DEACTIVATE VIRTUAL ENVIRONMENT
========================================
deactivate

========================================
6. CHECK INSTALLED PACKAGES
========================================
pip list

========================================
7. UPGRADE PIP
========================================
python -m pip install --upgrade pip

========================================
8. CHECK PYTHON VERSION
========================================
python --version

========================================
9. CHECK FLASK INSTALLATION
========================================
python -c "import flask; print(flask.__version__)"

========================================
TROUBLESHOOTING COMMANDS
========================================

Find process on port 5000 (Windows):
netstat -ano | findstr ":5000"

Kill process (Windows):
taskkill /PID <PID> /F

Find process on port 5000 (Linux/macOS):
lsof -i :5000

Kill process (Linux/macOS):
kill -9 <PID>

Check MySQL status (Windows):
sc query MySQL57

Start MySQL (Windows):
net start MySQL57

Stop MySQL (Windows):
net stop MySQL57

========================================
FAQ & QUICK FIXES
========================================

Q: Python command not found?
A: Add Python to PATH or use python3

Q: pip command not found?
A: Use python -m pip instead: python -m pip install -r requirements.txt

Q: Module not found errors?
A: Activate venv and reinstall: pip install -r requirements.txt

Q: Port 5000 in use?
A: Kill process or use different port: app.run(port=5001)

Q: MySQL connection refused?
A: Start MySQL service or check credentials

Q: "source" command not recognized (Windows)?
A: Use: type database.sql | mysql -u root -p

Q: Permission denied on setup.sh?
A: Run: chmod +x setup.sh

Q: Database changes not showing?
A: Clear browser cache (Ctrl+F5 / Cmd+Shift+R) or restart Flask
